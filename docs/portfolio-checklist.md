# Portfolio Publication Checklist

- [ ] Confirm permission to publish the `.pbix` and underlying data.
- [ ] Verify data source, data dictionary, model relationships, and measure definitions.
- [ ] Add a dashboard screenshot to `images/` (remove sensitive information).
- [ ] Add dataset provenance, license, date range, and row count.
- [ ] Complete KPI values and analysis findings from validated data.
- [ ] Add at least three evidence-based business recommendations.
- [ ] Test all visuals, slicers, date filters, and map interactions.
- [ ] Check spelling, formatting, and consistency between README and dashboard.
- [ ] Add contact/profile links only if intended for public viewing.
